# Historical design scripts
These are the saved generators and renderers from the design iterations. Input STL paths have been changed to repository-relative source_models paths. Run scripts from the repository root.

Dependencies used: Python, numpy, scipy, trimesh, manifold3d and matplotlib. Some renderers depend on intermediate meshes from earlier generators, and historical scripts may need directories created first. They are an archive of the workflow, not a verified one-command rebuild system. Saved outputs are the authoritative published artifacts.
